# Implementation Status

- 50-part campaign indexing.
- Story event playback.
- Story color presentation.
- Fight transitions.
- Normal win-required encounters.
- Scripted loss-required Arowh encounters.
- Best-of-three matches (configurable per story event).
- Player movement/jump/light/heavy/rage.
- Basic enemy approach/attack AI.
- Explicit fighter action states (neutral, attacking, hit-stunned, defeated).
- Round-start and round-end command locking with touch-input release.
- Health, stamina and rage HUD.
- Touch controls.
- Campaign progress save/reset.
- Runtime use of exported `chug.glb` / `enemy.glb` when supplied.
